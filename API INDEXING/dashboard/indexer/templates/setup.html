Demo

Loads this blog's real post list plus a few sample posts, and simulates Google's answers. Pushed URLs get "crawled" after about a minute and "indexed" after three, so you can watch the whole flow.

Google Cloud checklist

  1. console.cloud.google.com → create / pick a project
  2. APIs & Services → Library → enable Web Search Indexing API and Google Search Console API
  3. IAM & Admin → Service Accounts → Create → Keys → Add key → JSON
  4. Search Console → property → Settings → Users and permissions → add the service-account email as Owner
